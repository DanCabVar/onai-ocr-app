# 06_history

Bitácora estable del proyecto. Sirve para evitar retrabajo y preservar decisiones sin contaminar los specs activos.

- `SPEC_HISTORY.md`: índice de specs, estado histórico y evidencia de cierre.
- `DECISIONS.md`: índice de decisiones tipo ADR.
- `INCIDENTS.md`: incidentes operativos o técnicos relevantes.
- `IMPLEMENTATION_LOG.md`: log cronológico de cambios importantes.
- `decisions/`: ADRs individuales.
