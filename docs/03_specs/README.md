# 03_specs

Contratos de trabajo para ONAI OCR.

## Estructura

- `active/`: specs pendientes, en curso o en revision.
- `done/`: specs cerrados, deployados o archivados.

## Regla

Antes de trabajar, abrir solo el spec activo asignado y los contextos/runbooks que cite. Al cerrar una tarea, mover/copiar el spec a `done/`, registrar el cierre en `../06_history/SPEC_HISTORY.md` y actualizar `../PLAN_MAESTRO.md`.

Cada spec debe incluir:

- tarea(s) relacionadas;
- objetivo;
- alcance incluido/excluido;
- archivos o módulos relevantes;
- criterios de aceptación;
- verificación mínima;
- riesgos;
- reporte esperado del agente.
